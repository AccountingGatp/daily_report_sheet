    Quick workflow

    1. Choose the report period (From / To). Use the same dates for every export.
    2. Collect the six source files for that period — where each one comes from is listed below.
    3. Upload them in step 2. You can drop them all at once; each is matched to its box automatically.
    4. Enter or paste the daily advertising spend in step 3 — or leave it blank and fill it in the Excel file later.
    5. Check the Overview: every source should be green for every date. Fix anything amber or red.
    6. Click Download daily report.

    File sources

    Six uploads power the report. Three are exported straight from Shopify; three come from the other Saint tools.

    1. COGS (supplier) Excel · .xlsx

    Where: generated by the SAINT COGS tool from the supplier's (Speedfulfill) order export.
    1. Open the SAINT COGS tool.
    2. Upload the supplier's raw order Excel for the period and process it (follow that tool's own SOP).
    3. Download the processed COGS workbook. It contains the order lines (Date, Price, Total cost) and a daily summary with the USD → AUD rate.
    4. If a date has no USD → AUD rate in that file, Saint Daily uses the rate from the most recent earlier date and notes it in the report.
    5. Upload it in box 1 · COGS.
    If a SKU has no price in the COGS tool the file shows #N/A. Saint Daily lists those lines in the Overview for review — enter a price, or click Skip to proceed with the file as it is.

    2. COGS Shopify CSV

    Where: Shopify Admin → Analytics → Reports → Cost of goods sold (by order / product).
    1. Open Analytics → Reports and search for “Cost of goods sold”.
    2. Set the date range to the report period and click Apply.
    3. Click the three dots → Export → CSV. Columns include Day, Order name, Product title, Cost of goods sold.
    4. Upload it in box 2 · COGS Shopify.

    3. Merchant fees Excel · .xlsx

    Where: reconciled and exported from the Saint Merchant tool, which builds the PayPal / Afterpay / Shopify fee tables.
    1. Collect the five inputs for the period: Shopify Net payments by order, Shopify Total sales by order, Shopify payment transactions export, PayPal activity download and Afterpay settlement report.
    2. Open Saint Merchant, upload the five CSVs and run Upload & reconcile.
    3. Download the merchant Excel output (PayPal, Afterpay and Shopify tables by date).
    4. Upload it in box 3 · Merchant fees.
    Merchant fees settle weekly — make sure the settlement / payout exports cover every day in the period, otherwise that day shows a gap.

    4. Sales reconciliation CSV or Excel

    Where: generated by the SaintEyewear Sales Journal tool.
    1. Open the Sales Journal tool.
    2. Upload the Shopify Total sales by order and Net payments by order CSVs for the same dates.
    3. Generate the journal and download the reconciliation file.
    4. Upload it in box 4 · Sales reconciliation.
    Saint Daily recalculates the reconciliation from the Shopify files and compares it with this file. Any difference is flagged in the Overview.

    5. Net payments CSV

    Where: Shopify Admin → Analytics → Reports → Net payments by order.
    1. Go to Analytics → Reports.
    2. Open “Net payments by order”.
    3. Set the date range and click Apply.
    4. Click the three dots → Export.
    5. Upload the CSV in box 5 · Net payments.

    6. Total sales CSV

    Where: Shopify Admin → Analytics → Reports → Total sales by order.
    1. Back in Reports, open “Total sales by order”.
    2. Use exactly the same date range as Net payments.
    3. Export the CSV.
    4. Upload it in box 6 · Total sales.

    Advertising spend Manual

    Where: each platform's ads manager — Meta, Google Ads, Pinterest, Snapchat, TikTok — daily spend in A$ for the same dates.
    1. Export or read the daily spend per platform.
    2. Type it into step 3, paste a block copied from a spreadsheet (Date + five columns, or just the five columns), or import a CSV.
    3. Or leave it blank: the five ad rows are left empty (highlighted) in the Daily Reporting sheet, and totals, profit and ROAS update when you type them in Excel.

    Fixing gaps

    You seeWhat to do
    Red on Total sales / Net paymentsThe Shopify export doesn't cover that date. Re-export with the full date range.
    Amber on COGS — “no product price (#N/A)”A SKU isn't priced in the COGS tool. Enter a USD price in the Overview, click Skip to proceed with the file as it is ($0), or add the price in the COGS tool and re-upload.
    Red / amber on Merchant feesA gateway's fees are missing for that date. Check that the PayPal / Afterpay / Shopify exports in Saint Merchant cover the whole week.
    Amber on Sales reconciliationThe uploaded file doesn't match the Shopify files — usually a different date range. Regenerate it from the same two CSVs.
    Blue “–” on Ad spendNot entered — fine. Fill the ad rows in the Excel file later.
